# Paso 3: Instalar la Fuente

Una vez que tienes acceso al archivo **`Fuente_dos.ttf`** (dentro de la carpeta `fonts/`), instalarlo es un proceso de un par de clics.

## Instalación en Windows
1. Haz **doble clic** sobre el archivo `Fuente_dos.ttf`.
2. Se abrirá una ventana de previsualización que te mostrará cómo luce la fuente.
3. En la parte superior de esa ventana, haz clic en el botón que dice **Instalar**.
4. *(Alternativa)*: También puedes hacer **clic derecho** sobre el archivo y seleccionar **Instalar** (o "Instalar para todos los usuarios").

## Instalación en macOS (Mac)
1. Haz **doble clic** sobre el archivo `Fuente_dos.ttf`.
2. Se abrirá el programa **Catálogo Tipográfico** (Font Book) mostrando una vista previa de la fuente.
3. Haz clic en el botón **Instalar tipo de letra** (Install Font) en la parte inferior o superior de la ventana.
4. La fuente se añadirá a tu sistema y estará lista para usarse.

> **¡Importante!** Si tenías abierto Microsoft Word, PowerPoint, u otro editor de texto antes de instalar la fuente, **debes cerrarlo y volverlo a abrir** para que el programa detecte la nueva tipografía instalada.
