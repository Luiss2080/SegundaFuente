# Paso 2: Descomprimir el Archivo

Si descargaste todo el proyecto como un archivo `.zip`, necesitarás extraer los archivos antes de poder instalar la fuente.

## En Windows
1. Abre tu **Explorador de Archivos** y ve a tu carpeta de **Descargas** (o donde hayas guardado el archivo).
2. Haz **clic derecho** sobre el archivo `.zip` que descargaste.
3. Selecciona la opción **"Extraer todo..."** (Extract All).
4. Elige dónde quieres guardar los archivos extraídos y haz clic en **Extraer**.
5. Se abrirá una nueva carpeta normal con todos los archivos del proyecto.

## En macOS (Mac)
1. Abre **Finder** y localiza el archivo `.zip` descargado.
2. Simplemente haz **doble clic** sobre el archivo `.zip`.
3. La utilidad de compresión de Mac (Archive Utility) extraerá la carpeta automáticamente en esa misma ubicación.

Una vez que tengas la carpeta extraída, navega dentro de ella hasta encontrar la carpeta llamada **`fonts`**. Ahí dentro estará el archivo clave: `LuissFuenteDos.ttf`.
