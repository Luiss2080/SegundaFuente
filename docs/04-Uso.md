# Paso 4: Cómo Usar la Fuente en Microsoft Word

¡Felicidades! Ya tienes **LuissFuenteDos** instalada en tu computadora. Ahora es momento de utilizarla en tus documentos.

## Pasos para usarla en Word
1. Abre **Microsoft Word** y crea un Documento en blanco (o abre uno existente).
2. En la pestaña de **Inicio** (Home), ubica la caja de selección de tipo de letra (donde suele decir Calibri o Arial).
3. Haz clic en la flecha para desplegar la lista y busca **`LuissFuenteDos`**. *(Puedes escribir "LuissFuenteDos" directamente en la caja para encontrarla más rápido).*
4. Selecciona la fuente y comienza a escribir en mayúsculas (letras A-Z) para ver los increíbles diseños personalizados.

### Consejos para un mejor resultado
- **Tamaño:** Debido a los detalles de los trazos, se recomienda usar esta fuente en tamaños grandes (por ejemplo, **48pt o 72pt**) para usarla como títulos, logotipos, o iniciales decorativas (Letras Capitulares).
- **Formatos web:** Si eres desarrollador web, en la carpeta `/fonts` hoy solo existe `LuissFuenteDos.ttf`; puede usarse en CSS con `@font-face` (los formatos `.woff`/`.woff2` aún no se generan).

¡Disfruta de tu nueva tipografía!
