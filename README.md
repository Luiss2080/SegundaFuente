# Zoofi Blueprint Font

¡Bienvenido al repositorio oficial de la tipografía **Fuente_dos**!

Esta es una fuente tipográfica personalizada originada a partir de diseños de diagramas vectoriales intrincados y estilizados, convertida en una fuente de texto completamente funcional y utilizable en editores como Microsoft Word, Adobe Illustrator y diseño web.

## 📂 Estructura del Repositorio

Para mantener el proyecto organizado, los archivos se dividen de la siguiente manera:

* **`/fonts`**: ¡Lo más importante! Aquí se encuentran los archivos finales listos para instalar (`.ttf`, `.woff`, `.woff2`, etc.).
* **`/src/original_svgs`**: Las imágenes SVG base originales (diseños con líneas punteadas y filtros).
* **`/src/processed_svgs`**: Las imágenes SVG vectorizadas en negro sólido; estas son las "imágenes que sirven" para compilar la fuente directamente, optimizadas como polígonos cerrados.
* **`/docs`**: Toda la documentación paso a paso para usuarios finales que quieran instalar la fuente.
* **`build_font.js`**: Script de Node.js utilizado para la compilación de la fuente.
